# Formats

Order stories by priority (critical → routine). Combine related stories into 3–5 themes. Use only facts from the approved clusters and the user's answers.

## Performance review / self-assessment (default)

600–900 words, first person, markdown with headings.

- **Summary** — 2–3 sentences on overall impact for the period.
- **3–5 achievement sections** — each: the problem, what I did, the result, my role.
- **Beyond the code** — mentoring, incidents, cross-team work (only if the user mentioned any).
- **Looking forward** — 1 short paragraph on growth or next focus. Keep it grounded; ask the user if unsure.

Tone: confident, not arrogant. Action verbs — built, led, designed, shipped, reduced, fixed. Translate tech into business terms (reliability → trust, performance → conversion) only when the user's context supports it. For security or critical fixes, name the risk mitigated.

## Promotion case

Same as above, but frame each theme against the *next* level's expectations: scope, ownership, influence beyond own work, technical judgment. Ask which level they're going for and, if they have one, their company's leveling rubric.

## Salary negotiation

Short (300–500 words). Lead with the 3 highest-value outcomes, quantified where the user provided numbers. Emphasise business impact and scope growth over technical detail.

## Resume bullets

5–8 bullets. Format: *verb + what + result*. One line each, numbers where given. No first person.

> - Migrated payment processing to Stripe, cutting failed payments by ~30%
> - Built real-time notification system used by 12k monthly users

## LinkedIn

- **Post** (150–250 words): a hook line, 2–3 achievements or lessons, a short reflection, 3–5 hashtags. Personable, not boastful, light on jargon. Plain text, line breaks between paragraphs.
- **Profile summary** (100–150 words): third person, top 3–4 accomplishments framed as ongoing expertise.

Remind the user to strip anything confidential before posting publicly.

## Always

- Leave `[metric?]` where a number would strengthen a claim but none was given, and list those spots after the output.
- Never state an outcome, number, stakeholder, or leadership role the user didn't confirm.
